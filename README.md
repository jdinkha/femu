# femu - An NES Emulator
f(rank's) emulator

## Downloading and Building
To download, use 'git clone --recurse-submodules https://github.com/jdinkha/femu.git' to download the required submodule

Or, run "git submodule update --init --recursive" if you cloned without downloading the submodule

Simply run 'cmake -S . -B build' then 'cmake --build build' in the project root to build
The program will be in femu/build/femu
